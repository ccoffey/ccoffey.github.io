# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Email
[coffey.cathal@gmail.com](mailto:coffey.cathal@gmail.com) with a clear
description, reproduction steps, and any suggested mitigation.

You can expect an acknowledgement within seven days. Once the report is
understood, a fix will be prepared privately when practical and the disclosure
will be coordinated with the reporter.

## Scope

This repository contains a static site generator, its source content, and the
deployed portfolio. Reports are especially useful for issues involving build
scripts, the local-only comment authoring server, dependency supply chain, or
accidental disclosure of sensitive data.
